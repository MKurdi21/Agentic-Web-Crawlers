# Inactive skill remediation

The Phase 4 candidate skill set had focused responsibilities but its paper-reading and verification instructions did not explicitly require document-wide result reconciliation, deterministic derived-number checks, atomic decomposition, or locator entailment. Phase 4 failures show why those steps matter: H03 used a local result as global best; H04 miscounted zero rows; many compound claims cited only one of several support locations.

Only `candidate_v4r/deploy_payload/skills/paper-evidence-processing/SKILL.md` and `verification-adjudication/SKILL.md` were revised. The paper skill now triggers result inventory, scope qualification, atomic claims, source-bound operands, and precise support locators. The verifier skill now asks whether each locator entails its proposition, checks derived arithmetic and later results, and separates model verification from human authority. Shared conditional detail lives in `deploy_payload/protocols/SCIENTIFIC_EVIDENCE_V3.md`; deterministic repeated logic lives in `hardened/scripts/scientific_v3.py`.

Expected generalized effect: the reader proposes narrower claims and complete evidence locations, while the verifier fails closed on a correct number paired with an unsupported comparison or locator. Regression risk: additional source-review effort and more unresolved items, including ten formerly supported claims restricted during the consumed-set replay. This is safer than silently retaining overbroad support, but Phase 4B must measure the effect on untouched reports. The five-skill decomposition remains a target rather than a quota; other skills were not altered or installed. No test fixture, model, or skill can grant trusted-human approval.
