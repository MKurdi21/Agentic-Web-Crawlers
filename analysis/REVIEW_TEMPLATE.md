# Per-Paper Evidence and Review Template

Copy this structure into the paper's evidence directory as `ledger.md` before
synthesis. Replace placeholders with source evidence; an empty template is not
a completed ledger. Save the subsequent verification as `review.md`.

## Identity and Accessibility

- Title, authors, document type, supplied publication information:
- Source path and SHA256:

- Accessible page range and apparent gaps:
- Actually inspected visual pages and objects:
- Text-only pages or objects:
- OCR use, extraction disagreements, unreadable material:
- Appendices and supplied/absent supplements:

experiments, claims, limitations, appendices, and supplied supplements. Mark
