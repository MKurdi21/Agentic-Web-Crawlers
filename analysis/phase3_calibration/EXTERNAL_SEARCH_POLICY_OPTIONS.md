# External Search Policy Options

Status: recommendation pending owner approval. No Phase 3 gap search is authorized.

Future candidate-specific external validation should begin only after a gap has a stable definition, traceable internal evidence, and an approved maturity level. The protocol must record databases and source families, exact queries, interfaces, dates, result counts, screening decisions, versions, and inclusion consequences.

Discovered prior work must update the gap status and preserve the earlier decision history. A null search result may be described only as “no relevant evidence was identified in the recorded sources and queries as of the recorded date,” never as proof that no work exists.

## Recommendation

Keep external search disabled until the owner approves eligible gap maturity, sources, query-review responsibility, inclusion handling, and authority to modify the corpus.
