# Web Method and Architecture Sources

Web sources inform architecture and review-method design. They do not replace the forensic audit or establish facts about the local corpus.

- [SQLite PRAGMA documentation](https://www.sqlite.org/pragma.html): PRAGMA configuration, `integrity_check`, and `foreign_key_check`. SQLite notes that unknown PRAGMAs can be ignored, supporting explicit readback verification.
- [SQLite foreign-key documentation](https://www.sqlite.org/foreignkeys.html): per-connection foreign-key enforcement behavior.
- [SQLite Online Backup API](https://www.sqlite.org/backup.html): consistent completed backup snapshots and backup mechanics.
- [SQLite WAL documentation](https://www.sqlite.org/wal.html): same-host/shared-memory constraints relevant to rejecting synced-workspace WAL as a production default.
- [OpenAI skill guidance](https://developers.openai.com/codex/skills/): focused skills, discriminating descriptions, progressive disclosure, deterministic scripts when required, and trigger testing.
- [Cochrane Handbook, Chapter 5](https://www.cochrane.org/authors/handbooks-and-manuals/handbook/current/chapter-05): pilot extraction, explicit instructions, careful data collection, and distinction between studies and reports.
- [PRISMA 2020](https://www.prisma-statement.org/prisma-2020): transparent reporting guidance. Phase 3 does not claim PRISMA compliance or a completed systematic review.

Consulted: 2026-09-14. Scientific calibration remains closed-document except for explicitly permitted authoritative bibliographic checks on known version relationships.
