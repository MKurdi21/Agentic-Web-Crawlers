# Partial Synthesis Policy

Status: recommendation pending owner approval.

## Options

- **Complete-only:** no authoritative synthesis until every in-scope report satisfies the approved verification threshold. Strong coverage, but delays all evidence-backed output.
- **Frozen verified subset:** synthesize only an explicitly selected and verified subset. Requires exact eligible and excluded report lists, denominator, coverage, protocol and taxonomy fingerprints, and a prominent incompleteness statement.
- **Tiered:** permit descriptive inventories over raw registered records while restricting scientific findings, contradictions, and gap claims to verified eligible evidence.

## Recommendation

Use the tiered option. Descriptive inventory counts must remain distinguishable from scientific findings. Evidence-backed synthesis must use a frozen verified subset, report both report and adjudicated research-object denominators, list exclusions and unresolved version groups, and preserve the exact evidence and policy fingerprints.

No partial synthesis is enabled by this document. Owner approval is required.
