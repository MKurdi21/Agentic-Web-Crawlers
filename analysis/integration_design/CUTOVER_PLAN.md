# Cutover Plan

No cutover command exists in this package. A later authorized phase must resolve storage/trust/policy choices,freeze and inventory current writers,preserve current baseline and ignored evidence,repeat shadow import/equivalence on frozen inputs,validate backup+artifact closure,calibrate retained-paper adapters,and review the exact install mapping before switching authority.

The dependency chain is preservation -> identity/state/provenance crosswalk -> hardened acceptance -> independent equivalence -> calibration/policy decisions -> authorized authority switch. Scientific source review may proceed from preserved drafts independently of an authority switch; contribution adjudication and taxonomy precede scientific synthesis. Do not impose blanket regeneration.

At eventual cutover,deploy only reviewed files via INSTALL_MANIFEST.json with expected live hashes and reversible backups. Keep old state engine and original manifests/checkpoints read-only as oracle/history. Reject changed live targets rather than overwriting user edits. Roll back on any identity,count,provenance,acceptance,storage or backup discrepancy.
