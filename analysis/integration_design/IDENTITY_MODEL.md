# Identity Model

SOURCE_FILE is content identity (sha256:<full hash>); observations retain every physical path and source version. PAPER_REPORT retains stable manifest SummaryName identity independently of physical path or title. RESEARCH_OBJECT is a scientific grouping represented through evidence-bearing relationship/record decisions; it is not a folder or duplicate-hash group.

Five archived copies share source identity with canonical reports and remain distinct observations. Mind the Web and AgentVigil probable versions retain separate report IDs and summaries. AGENTFUZZER is a historical filename alias, not proof of another contribution. The audit's2 probable groups are UNRESOLVED; 112 reports must not become112 independently confirmed research objects. Historical paths and aliases are preserved even where old links are broken.

Source mutation records new source bytes separately and invalidates old tasks. Similar titles never drive merging. Alias collisions and missing sources block import rather than overwriting another record. A future adjudication preserves prior membership, reviewer, exact evidence and supersession; source/report IDs are never recycled.
