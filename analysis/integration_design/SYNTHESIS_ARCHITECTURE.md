# Synthesis Architecture

Synthesis is an accepted,versioned evidence computation with exact input IDs/hashes,coverage,exclusions and both report/object denominators. Canonical sorted (record_id,artifact_sha256) pairs define its fingerprint. Inputs must remain current and reviewed; confirmed research objects must cover the same included reports. Partial coverage requires an explicit policy; the current implementation fails closed because that policy is unconfigured.

Outputs support cross-paper evidence matrices,contradiction and replication context,gap candidates and downstream RQs. Contradictions reference real comparable claims; a matrix's empty cell alone does not establish a novel gap. Historical docs and the48-summary synthesis are imported as raw historical artifacts,not silently recast as a112-report review.

Registration and deterministic constraints do not prove the narrative's scientific accuracy. Scientific verification,contribution resolution,taxonomy governance and actual synthesis review are future work on preserved inputs. This release tests eligibility/fingerprints/denominators and records limitations; it does not generate a new literature review.
