# Taxonomy Governance

Taxonomy terms have stable IDs,definitions,inclusion/exclusion boundaries and semantic version. Paper coding cites existing terms at the exact current taxonomy version and source evidence. Folder membership and historical filename-regex tags may seed proposals but are not accepted taxonomy coding.

Taxonomy changes require owned proposals,rationale,review and supersession. Recode only affected paper coding and dependent synthesis; retain summaries and original codes/version history. Empty code arrays,undefined terms and ungrounded evidence links fail deterministic validation. Disagreements require adjudication rather than silent majority labeling.

Production governance and final inclusion criteria remain open. Synthetic fixtures exercise term/version checks; no project taxonomy has been installed or assigned to actual papers. The heavy prompt remains unchanged and may inform future code definitions without becoming a replacement evidence schema.
