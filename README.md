# AI web-agent trap research foundation

This repository preserves the literature, source records, analysis, citations and novelty assessment for research on crawler-like adversarial traps targeting autonomous AI web agents.

**Working research question:** How can adversarial web environments induce and sustain task-dependent navigation traps in autonomous AI web agents, and what determines whether agents escape, recover, or continue unproductive interaction?

The leading proposal tests task-relevant recurring prerequisites in a solvable environment with an available escape. Classical crawler traps motivate the question; goal interpretation, semantic progress claims and recovery distinguish the proposed agent study. Existing navigation traps, persuasion and iterative resource attacks constrain novelty. No new trap experiment has been implemented or run in this task; the experiment program has not started.

## Research priorities

1. **H1, primary:** Task-relevant recurring prerequisites increase bounded non-progress interaction compared with neutral framing on equivalent recurring structures.
2. **H2, supporting:** Task relevance interacts with recurrence, producing an effect beyond topology alone.
3. **H3, exploratory intervention:** Appropriate progress-aware escape strategies can reduce non-progress work without substantially damaging legitimate iterative task performance.

These are untested hypotheses. The proposed pilot is exploratory feasibility; a later confirmatory protocol needs independent task families and a fixed analysis. Entry, retention, verified progress, escape, safe termination, recovery and resource use remain distinct. Broad first-attack claims are unsupported. Memory, multimodal manipulation, adaptation, action security and the standalone comparison remain supporting research.
