## Scope and classification rules

This report focuses on academic papers about agentic AI systems that interact with the web through crawling, browsing, scraping, traversal, website exploration, web search, browser control, or tool-based web automation.

Security is **not** the only focus. However, each paper is marked as security-related when it involves prompt injection, indirect prompt injection through webpages, malicious or adversarial webpages, poisoned web content, attacks against web agents, privacy leakage, data exfiltration, unsafe tool use, web-agent abuse, phishing/scams/malware/social engineering, crawler/scraper abuse or defense, sandboxing/containment, or trustworthiness/robustness/safety of autonomous web agents.

## Final synthesis

The most important directly relevant papers are **Mind2Web**, **WebArena**, **VisualWebArena**, **WebVoyager**, **WebLINX**, **WorkArena/WorkArena++**, **BrowserGym**, **WebShop**, **AutoWebGLM**, **SeeAct**, **AutoScraper**, **WebWalker**, **WebDancer**, **WebSailor**, **BrowseComp**, and **BEARCUBS**. These form the core literature for autonomous web browsing, browser automation, website traversal, web information seeking, and LLM-based scraping.

Security-related papers include **WASP**, **SafeArena**, **ST-WebAgentBench**, **WARD**, **Unsafe LLM-Based Search**, **When AI Meets the Web**, **YuraScanner**, **Prompt Injection Attack to Tool Selection in LLM Agents**, **Overcoming the Retrieval Barrier**, **ACE**, **Attention is All You Need…**, and **Identifying AI Web Scrapers Using Canary Tokens**.

For Big 4 security, the clearest directly relevant papers appear in **IEEE S&P 2026**, **USENIX Security 2025/2026**, and **NDSS 2025/2026**. I found **no main ACM CCS paper** that directly centers autonomous web agents or browser agents in the same way; the closest ACM result is the AISec 2023 indirect prompt-injection paper.

The literature is mostly from **AI/NLP/web/HCI-style venues and preprints**, not primarily from security venues. Security venues are now catching up through prompt injection, malicious webpages, unsafe search, tool-use security, and web-agent misuse benchmarks.

Open gaps remain around:

- true crawling at web scale
- LLM-guided scraper/crawler abuse and defense
- long-horizon web traversal under adversarial webpages
- standardized security evaluation for real browser agents
- privacy leakage during browsing
- agent containment/sandboxing
- benchmark realism versus safety
- repeatable evaluation on live websites without causing harm or violating website terms
